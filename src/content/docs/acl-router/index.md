Plantilla comentada de listas de acceso para router, pensada para partir de una base legible en vez de una lista de reglas sin contexto.

## Orden de las reglas

Las reglas más específicas van antes que las generales, y cada bloque de reglas lleva un comentario con el motivo por el que existe, no solo qué hace.
